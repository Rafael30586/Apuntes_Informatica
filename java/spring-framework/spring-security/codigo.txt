Cuando usamos el método httpBasic en el objeto HttpSecurity estamos agregando un esquema de autenticación muy básico en el cual se envía el usuario y la contraseña en cada solicitud HTTP. El cliente codifica las credenciales en base64 y las incluye en las cabeceras en el apartado Authorization. No es la forma más segura de implementar esto. Para comprobar su funcionamiento con postman se utiliza BasicAtuh. Postman enviará el usuario y la contraseña en las cabeceras de cada solicitud
