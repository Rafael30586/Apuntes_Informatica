colors --> permite modificar el color de lo que se imprime en consola. Se instala con npm install colors

nodemon --> sirve para que no tengamos que volver a ejecutar la aplicación de manera manual para poder ver los cambios que hayamos hecho en el código

dotenv --> es para la utilización de variables de entorno en el proyecto

env-var --> sirve para mostrar las variables de entorno según diferentes tipos, por ejemplo, number

json-server --> permite trabajar con una base de datos en memoria
