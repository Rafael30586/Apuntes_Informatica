Node permite la ejecución de JavaScript afuera del navegador

----------------------------
Comparación entre JavaScript del browser y JavaScript de node js:
* En Node no hay acceso a APIs del browser (no hay DOM, geolocación, fetch, etc) 
* En Node no hay DOM
* En node se puede acceder al sistema de archivos, información del sistema operativo, etc
* En node hay módulos por defecto

--------------------------
Si abrimos la consola y utilizamos el comando node se abre un REPL. En este REPL podemos hacer cosas relacionadas al lenguaje de programación, como crear variables, usar funciones, etc. Para salir del REPL hacemos ctrol + c

-------------------------
En node no hay un objeto window como en javascript en el navegador porque no hay una ventana

------------------------
En Node hay variables globales, podés acceder a ellas desde cualquier lugar de tu aplicación.

* __dirname --> es la ruta a donde está el archivo js
* __filename --> es la ruta en donde se encuentra el archivo (incluyendo el nombre del archivo)
* process --> tiene un montón de información sobre la computadora en la que el archivo está funcionando. Es un objeto que tiene muchos atributos y podemos acceder a ellos, por ejemplo, process.version

-----------------------
En node podemos usar funciones como setTimeout y setInterval

-------------------------
En node todo archivo es un módulo

-----------------------
Para exportar el contenido del módulo en el que estamos debemos hacer module.exports = {<variable-o-función>, <variable-o-función-2>, ...}
Podemos exportar más de una variable o función por módulo. Luego podemos importar el módulo en otro con const <variable> = require(./<nombre-módulo>)

Cuando queremos exportar solo una función, podemos obviar los corchetes, por ejemplo, module.exports = saludo

------------------------
Podemos importar un módulo que no está exportando nada. Si hacemos esto lograremos que, al ejecutar el módulo que miporta, también se ejecute el módulo importado

------------------------
En node hay algunos módulos integrados, como por ejemplo: OS, Path, FS y HTTP

En la página oficial de node hay documentación sobre estos módulos: https://nodejs.org/docs/latest/api/

El módulo os sirve para interactuar con el sistema operativo. Se puede extraer información sobre los CPUs lógicos, interfaces de red, memoria, etc

Cuando utilizamos el módulo fs, tenemos acceso a funciones síncronas y asíncronas. Las primeras son código bloqueante, mientras que las segundas son código no bloqueante

----------------------------
El archivo package.json es el manifest file de cada proyecto de node. Se encuentra en el directorio raíz. Podemos crearlo de manera manual o utilizando el comando npm init
