Módulos --> es un mecanismo de organización y encapsulación que se utiliza para agrupar componentes, directivas, pipes, servicios y otros elementos relacionados en una unidad funcional coherente. Los módulos ayudan a dividir una aplicación en partes más pequeñas y manejables, lo que facilita el desarrollo, la mantenibilidad y la escalabilidad. Un módulo no es lo mismo que un componente, los módulos no se ven, los componentes sí

Componentes --> son un bloque fundamental de construcción para la creación de interfaces de usuario en una aplicación web. Los componentes son responsables de definir cómo se ve y se comporta una parte específica de la interfaz de usuario de la aplicación. Cada componente representa un elemento visual o funcional de la página web, como un encabezado, un pie de página, un formulario, una lista de elementos, etc. Un componente no es un solo archivo, tiene un archivo .ts , una plantilla en HTML y un archivo de estilos en CSS

Directivas --> Son instrucciones en el marcado HTML que proporcionan funcionalidad adicional a los elementos del DOM existentes o personalizan su comportamiento. Las directivas son un componente clave en la construcción de aplicaciones web en Angular, ya que permiten extender y manipular el DOM de manera declarativa, lo que facilita la creación de interfaces de usuario dinámicas e interactivas. Angular proporciona varias directivas incorporadas y también permite la creación de directivas personalizadas

Pipes --> Son una característica que permite formatear y transformar datos en la vista de una aplicación web de manera sencilla y legible. Los pipes son funciones que toman un valor de entrada (como una cadena de texto, un número o un objeto) y lo procesan para proporcionar una representación modificada o formateada en la interfaz de usuario. Los pipes se utilizan en las plantillas HTML de Angular y se aplican utilizando el símbolo de barra vertical | . Algunos ejemplos comunes de usos de pipes incluyen el formateo de fechas, números, monedas, texto en mayúsculas o minúsculas, entre otros. Angular proporciona un serie de pipes integrados y también podés crear tus propios pipes

Enrutamiento --> Se refiere a la capacidad de navegar entre diferentes componentes o vistas de una aplicación web sin recargar la página completa. Permite crear aplicaciones de una sola página (SPA) donde los cambios en la URL desencadenan la carga de diferentes componentes, proporcionando así una experiencia de usuario más fluida y rápida

Estructuras de control --> son herramientas que nos permiten manipular el flujo de ejecución de la aplicación. Ejemplos: ngIf, permiten mostrar u ocultar un elemento en función de una expresión booleana; ngFor, utilizado para iterar sobre una lista renderizar elementos repetitivos; ngSwitch; ngClass, permite cambiar de manera dinámica la clase de un elemento; ngStyle, permite cambiar dinámicamente los estilos de un elemento; ngContainer, no afecta al DOM, se utiliza para agrupar elementos sin agregar nodos adicionales al árbol DOM (es como el fragment de React)
