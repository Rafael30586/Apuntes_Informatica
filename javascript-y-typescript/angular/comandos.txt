npm install -g @angular/cli@<versión> --> sirve para instalar el CLI de Angular 16

npm unistall -g @angular/cli --> desinstala todas las versiones de Angular CLI

ng new <nombre> --> crea un proyecto de Angular según el nombre que elijamos

ng generate module <nombre> --> crea un módulo según el nombre que indiquemos

ng g m <nombre> --> idem al anterior

ng generate component <nombre> --> crea un componente

ng g c <nombre> --> idem al anterior

npm start --> ejecuta el proyecto

ng generate service <nombre> --> crea un servicio

ng g s <nombre> --> idem al anterior

ng generate directive <nombre> --> crea una directiva

ng g d <nombre> --> idem al anterior

Nota: cuando se crean componentes, servicios o directivas en Angular que tengan un nombre con más de una palabra, conviene separar las palabras por un guión medio, por ejemplo: ng g c un-componente ; pero cuando hagamos ng new para crear un nuevo proyecto, el nombre de dicho proyecto deberá ir en camel case

ng generate pipe <nombre> --> crea un pipe

ng g p <nombre> --> idem al anterior

npm run build --> transforma la aplicación en código HTML, CSS y JavaScript y lo coloca en la carpeta dist

Cuando creamos servicios o pipes en Angular conviene colocarlos en subcarpetas. Para hacer esto se utiliza, por ejemplo, el comando ng g s servicio/<nombre>
