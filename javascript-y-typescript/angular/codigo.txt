{{ variable }} --> se utiliza para mostrar el valor de una variable del componente en la plantilla

<button (click)="decrementar()">Decrementar</button> --> ejemplo de cómo se utilizan los eventos. En este caso el evento es click y se llama al método decrementar del componente que puede modificar algún atributo

El decorador @Input() sirve para que un atributo de un componente reciba datos de un componente padre

El decorador @Output sirve para que un componente le envíe datos a una componente padre

Cuando se utilizan servicios, estos pueden inyectarse en los componentes vía inyección de dependencias. Una de las formas de hacerlo es por constructor

Para utilizar Bootstrap en angular hay que instalarlo con los comandos que aparecen en la página oficial de Bootstrap. Luego, hay que editar el archivo angular.json de manera tal que en la parte de styles y script coloquemos la ubicación de los archivos bootstrpa.min.css y Bootstrap.bundle.min.js respectivamente

Cuando queramos agrupar varios elementos HTML en uno podemos usar ngContainer (es similar al fragment de React)

Para trabajar con formularios hay que importar FormsModule (es para formularios de tipo plantilla), y si se quiere trabajar con formularios reactivos debe importarse ReactiveFormsModule

Cuando utilizamos ngDoCheck hay que tener cuidado de no utilizar con este operaciones muy costosas, ya que se ejecuta a cada rato y haría a la aplicación muy lenta

Para conectarse con APIs hay que importar el módulo HttpClientModule
