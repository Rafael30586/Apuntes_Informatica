* Tupla: es la fila de una tabla en una base de datos
* Dominio: es el tipo de dato definido para una columna en una base de datos. Este tipo de datos puede ser un tipo integrado (como integer y string), o un tipo personalizado que define restricciones de datos. Según chatGPT el dominio es el conjunto de datos válidos para un atributo, por ejemplo, para varchar(100), el dominio sería todas las cadenas de caracteres que tengan hasta 100 caracteres
